# AnalysisOfAlgorithmsHomework1

# sorting algorithms project

this project implements merge sort and quick sort. it uses both python and java. the code covers arrays and linked lists.

## content

**8 sorting implementations:**
* **python:** merge sort and quick sort using arrays.
* **python:** merge sort and quick sort using linked lists.
* **java:** merge sort and quick sort using arrays.
* **java:** merge sort and quick sort using linked lists.

**tools:**
* `benchmark.py`: this script tests all the code. it uses sizes from 2^1 to 2^12.
* `visualize.py`: this script creates performance charts.

## quick start

1.  **run the benchmarks:**
    ```bash
    python3 benchmark.py
    ```

2.  **create the charts:**
    ```bash
    python3 visualize.py
    ```

3.  **read the analysis:**
    open `analysis.md`. it explains the performance results.
